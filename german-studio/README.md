# استودیو آلمانی لی‌لی

یک PWA آفلاین و فارسی‌محور برای حرکت از صفر تا C1. این برنامه در پوشه‌ای مستقل قرار دارد تا هیچ‌یک از فایل‌ها و سرویس‌های قبلی مخزن `lili` تغییر نکنند.

## آنچه اکنون آماده است

- حداکثر ۵ پروفایل محلی با پیشرفت کاملاً جدا
- نقشه ۲۴ماهه از A0 تا C1
- آزمون مقدماتی A1 تا C1 و تشخیص شروع از A0
- برنامه روزانه، حالت روز شلوغ و benchmark ماهانه
- فلش‌کارت SM-2، تمرین گرامر و تبدیل خطاها به کارت
- تلفظ آلمانی با TTS مرورگر، shadowing و تمایز آوایی
- ضبط مکالمه، موقعیت‌های واقعی و تمرین ارائه/بحث
- نوشتن ایمیل، متن استدلالی و خلاصه همراه با پرامپت ارزیابی CEFR
- گزارش پیشرفت، خروجی و بازیابی JSON و کارکرد آفلاین

## اجرای محلی

به‌علت Service Worker، برنامه را از یک وب‌سرور محلی اجرا کنید:

```bash
cd german-studio
python3 -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید.

## نکته مهم درباره کاربران و داده‌ها

این نسخه برای یک خانواده یا گروه کوچک حداکثر پنج‌نفره طراحی شده است. پروفایل‌ها و پیشرفت در همان مرورگر ذخیره می‌شوند و ورود اینترنتی یا همگام‌سازی بین دستگاه‌ها ندارند. برای استفاده روی چند دستگاه یا کنترل دسترسی واقعی، فاز بعدی باید احراز هویت و پایگاه داده سمت سرور داشته باشد.

## مسیر پیشنهادی تکمیل

1. گسترش محتوای ثابت هر سطح به حداقل ۸۰–۱۲۰ درس کوتاه و افزودن آزمون پایان سطح.
2. افزودن تمرین شنیداری دارای فایل صوتی و متن، با مجوز روشن.
3. افزودن سنجش تلفظ با STT و rubric؛ امتیاز فعلی فقط خودارزیابی است.
4. ساخت backend سبک برای ۵ حساب، همگام‌سازی و پشتیبان‌گیری رمزگذاری‌شده.
5. افزودن پنل مربی برای مشاهده نقاط ضعف، تعیین تکلیف و خروجی هفتگی.
6. آزمون کاربردپذیری با زبان‌آموزان واقعی A0، A2 و B1 پیش از تولید محتوای انبوه.

این محصول ابزار تمرین است و مدرک یا ارزیابی رسمی Goethe/telc ارائه نمی‌کند.
